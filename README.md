# Insurance School of Texas — logo pack

Rebuilt 20 Aug 2026. The earlier files carried a rendering artefact: two leftover
copies of the ring text ("INSURANCE SCHOOL" / "OF TEXAS") were sitting off the top-left
of the artboard as flat white paths. On a white background they were invisible. On a
blue/navy background the bottom sliver of them showed as faint marks across the top-left
corner. They have been removed from the source artwork, so every file here is clean.

| File | Use |
|---|---|
| `isot-logo-color.svg` / `.png` | Main logo. Transparent background. Works on white or light backgrounds. |
| `isot-logo-white.svg` / `.png` | All-white version for navy, black or photo backgrounds. |
| `isot-logo-white-gold.svg` / `.png` | White + gold version for navy backgrounds. |
| `isot-logo-color-600.png` | 600x670 — the size used in the WooCommerce order emails. |
| `isot-favicon-512.png` | 512x512 — the browser tab / home-screen icon source. |
| `*-on-white.jpg` / `*-on-navy.jpg` | Flattened previews for anything that cannot handle transparency. |

SVG is the master: it stays sharp at any size. Use the PNGs where SVG is not accepted
(Word, PowerPoint, most social profiles).

## If SVG will not open

SVG is a web format. Phones and most chat apps will not preview it, and some just spin
forever trying. Use the **PDF** instead — it is the same vector artwork, stays sharp at any
size, and opens natively on a phone, a Mac, Windows and in any print shop.

| File | Use |
|---|---|
| `isot-logo-color.pdf` | Main logo, vector. Give this to printers, sign makers and designers. |
| `isot-logo-white.pdf` | All-white version, vector. |
| `isot-logo-white-gold.pdf` | White + gold version, vector. |
| `*-2400.png` | 2400px wide, transparent. For anything that wants a big image file. |
